LOOM — Production Launch

Five threads to weave before LOOM leaves the loom.

Hosting, deployment, monitoring, legal, and go-to-market — each one crosses the same warp thread: the decision below about whether LOOM stays bring-your-own-key.

Hosting & Domain

ready to move

Stay on GitHub Pages if bring-your-own-key; move the API layer to Vercel or Railway only if a backend gets added. Either way, point a custom domain at it.

Continuous Deployment

not started

A GitHub Actions workflow deploying on push to main — no build step needed for the current single-file structure.

Monitoring

not started

Sentry's free tier on the router's dispatch logic, so a silent Warp/Weft/Heddle/Selvage failure surfaces before a user reports it.

Payments & Legal

conditional

Only needed if LOOM becomes a hosted, paid product — Stripe Billing, a Privacy Policy disclosing that inputs reach Anthropic's API, and a one-page Terms of Service.

Go-to-Market

not started

Product Hunt, dev communities, and the visible reasoning trace as the hook — no pitch deck or CRM required at this stage.

The fork in the road

Every thread above depends on this one choice.

Stay BYOK

recommended for MVP
  • No backend, no billing, no held keys
  • GitHub Pages is sufficient
  • Launch in days
  • Validates demand before complexity

Go Hosted

once demand is proven
  • Backend required to hold & meter the key
  • Enables charging for LOOM itself
  • Adds billing, privacy policy, ToS
  • Launch in weeks, not days

Immediate next steps

  3. Wire in Sentry.
  4. Buy the domain.
  5. Prepare the Product Hunt launch post and demo video.
